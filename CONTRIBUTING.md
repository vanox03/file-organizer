# Contributing

Thanks for helping improve File Organizer.

## Development Setup

1. Fork and clone the repository.
2. Create a focused branch from `main`.
3. Install development dependencies with `python -m pip install -e ".[dev]"`.
4. Make the change and add or update tests.
5. Run `ruff check .` and `pytest`.
6. Open a pull request explaining the behavior and verification performed.

Keep changes small and avoid destructive defaults. New organizing behavior must
preserve the guarantees documented in the README.

By contributing, you agree that your contributions will be licensed under the
project's MIT License and that you will follow the Code of Conduct.
